## Mandatory workflow

Before editing any file:

1. Confirm the current working directory is the repository root.
2. Run `git status`.
3. Inspect the relevant existing files before proposing changes.
4. State which files you intend to modify.
5. Do not edit files outside this repository.

After editing:

1. Run a production build using the first command available in the current environment:
   - `pnpm run build`
   - `npm run build`
   - `pnpm.cmd run build`
   - `npm.cmd run build`
2. If one command is unavailable, try the next available command.
3. The build must complete successfully.
4. Report which build command was used.
5. Review `git diff` and summarize changed files.
6. Do not commit or push unless the user explicitly asks.

## Asset path rules

All files stored under `public` must be referenced without the word `public`.

Correct:

- /images/example.jpg
- /videos/example.mp4
- /documents/resume.pdf
- /models/orchid.glb

Incorrect:

- ./public/images/example.jpg
- /public/images/example.jpg
- C:\Users\...
- file:///C:/...

Never introduce `./public/` into HTML, CSS or JavaScript.

## JavaScript synchronization rule

This project currently contains:

## Vite build rules

Cloudflare Pages uses:

- Build command: npm run build
- Build output directory: dist
- Root directory: repository root

Do not change the output directory away from `dist`.

The project is a multi-page Vite site. When adding a new HTML page, also add it to `build.rollupOptions.input` in `vite.config.js`.

Do not remove existing HTML entries from `vite.config.js`.
